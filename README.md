# Dataset Description

## Animals-10 Dataset

This project uses the **Animals-10 dataset** for household animal image classification using deep learning. The dataset contains images belonging to 10 animal categories and is used to train and evaluate two transfer-learning models: VGG16 and EfficientNetB0.

### Dataset Source

- **Dataset name:** Animals-10
- **Platform:** Kaggle
- **Dataset URL:** https://www.kaggle.com/datasets/alessiocorrado99/animals10
- **Task:** Multiclass image classification
- **Number of classes:** 10

### Animal Categories

The dataset contains images of the following animals:

1. Dog
2. Horse
3. Elephant
4. Butterfly
5. Chicken
6. Cat
7. Cow
8. Sheep
9. Spider
10. Squirrel

### Data Organization

The images are organized into folders according to their animal categories. During preprocessing, the images are prepared for model training and evaluation. The dataset is divided into training, validation, and testing subsets to support model development and performance assessment.

### Usage

The dataset is used to compare VGG16 and EfficientNetB0 based on classification performance and evaluation metrics. The results help identify the strengths of each model for animal image classification.

### Dataset Availability

The complete dataset is not stored in this GitHub repository because of its size. Users should download it from the original Kaggle source and follow the preprocessing instructions in the project notebook.
